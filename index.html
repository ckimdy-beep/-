중요: 휴대폰에서 content://로 HTML 파일을 직접 열면 음성 인식이 작동하지 않을 수 있습니다. 2차 버전은 HTTPS 웹주소에서 사용하는 것을 기준으로 만들었습니다. Chrome의 사이트 마이크 권한도 허용되어 있어야 합니다.

API 키는 이 브라우저의 localStorage에만 저장됩니다. 여러 사람이 사용하는 공개 배포에서는 브라우저에 키를 넣지 말고 서버 프록시를 사용해야 합니다.

아이와 사용하는 경우: 이름·학교·주소·연락처·비밀번호 등 개인정보를 묻지 않고, 무섭거나 어른용 주제를 다루지 않도록 설정합니다.
